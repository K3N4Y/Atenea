# Architecture decision records

This directory records architectural decisions that are costly to reverse,
surprising without context, and based on a meaningful trade-off. Read the ADRs
that touch an area before changing its architecture.

ADRs use sequential four-digit numbers and descriptive slugs, for example
`0001-example-decision.md`. Add each new ADR here and to the Architecture
section of [the OKF index](../../README.md).
