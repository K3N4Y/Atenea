Searches files

<instruction>
- pattern: one ripgrep regular expression; use `|` for alternatives, such as `TODO|FIXME`.
- path: one workspace-relative file or directory to search; use separate calls for independent search roots.
- include: one optional file-name glob; use braces for alternatives, such as `*.{go,md}`.
</instruction>

<critical>
- MUST use this instead of shell `grep`/`rg`.
- Open-ended multi-round
</critical>
