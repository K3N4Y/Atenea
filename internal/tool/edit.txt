Edits existing files with line-anchored patches.

<instructions>
- read before edit a file
- Start each file section with `[PATH#TAG]`, using the 4-hex snapshot tag from the latest `read` or search result.
- Use `PUT N.=M:` to replace lines, `PUT <N:` or `PUT >N:` to insert, and `CUT N.=M` to delete.
- Every replacement or insertion line starts with `+`; the body contains final content, not a diff.
- Use `PUT N*:` or `CUT N*` for a complete syntactic block beginning at line N.
- Use `CUT ... @name` and a bodyless `PUT ... @name` to move captured content.
- Use `MV DEST` to rename or move a file.
</instructions>

<avoid>
- Editing lines not displayed by the latest read or search.
- Reusing line numbers or snapshot tags after an edit.
- Widening a range to include unchanged lines.
- Using edit to create new files; use write instead.
</avoid>

<critical>
- Re-read after every edit before making another change to the same file.
- Ranges refer to original inclusive line numbers; body length does not affect the range.
- Use `CUT`, never an empty `PUT`, to delete content.
- Validate the edit result before continuing.
</critical>
