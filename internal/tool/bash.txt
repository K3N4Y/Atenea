Run real terminal programs through `bash -c`.

<instructions>
- command: the complete non-interactive shell command; each call starts a fresh process in the workspace, so cwd, variables, and aliases do not persist.
- Set `slow_ok=true` for builds, tests, downloads, and installations that may exceed the short timeout.
- Chain dependent steps in one `command`; use separate calls for independent commands.
- Every command requires user approval before execution and may be denied.
- `$ATENEA_RAH_CLIENT` is present only during explicitly activated Recursive Agent Harness turns. When present, generated programs may pipe a version-1 batch JSON document to `"$ATENEA_RAH_CLIENT" __rah_batch`.
</instructions>

<avoid>
- Do not use bash for reading, searching, or editing files covered by dedicated workspace tools.
- Do not launch editors, pagers, password prompts, or other interactive processes.
- Do not assume `cd` or `export` persists between calls.
</avoid>

<critical>
- Use bash to execute programs, not for file operations covered by dedicated workspace tools.
- Mark potentially slow commands with `slow_ok=true`.
- Treat a nonzero exit as evidence to inspect; do not blindly retry.
- If a command is denied, do not repeat it; explain its purpose or choose a dedicated safe tool.
- If an executable or flag is missing or invalid, correct the command without concealing the failure.
</critical>
