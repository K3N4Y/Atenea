Read files

<instructions>
- path: one workspace-relative text file; append `:N` for one line or `:N-M` for an inclusive line range, such as `src/foo.go:50-200`.
- A read returns at most 2,000 lines, 30 KiB, and 2,000 characters per displayed line; continue from the range named in the truncation notice.
- Use `glob` to find files by name and `grep` to locate content before reading the relevant section.
</instructions>

<critical>
- Never infer content outside the returned line range.
- Never fabricate a `[path#HASH]` snapshot header; read the file again if no header is returned.
- Read only workspace text files; use the appropriate tool for directories, binary files, URLs, archives, databases, documents, or images.
</critical>
