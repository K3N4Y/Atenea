Use Language Server Protocol (LSP) features through one persistent language server per workspace and language. Operations: diagnostics, definition, references, symbols, and rename. Every call requires a workspace file path. Definition, references, and rename use 1-based line and column; rename also requires new_name. Symbols with an empty query lists document symbols, while a nonempty query searches workspace symbols. Results use jumpable workspace-relative path:line:column locations. Rename validates and applies the server's workspace edit and returns a UI diff; it refuses edits outside the workspace and unsupported file operations. The appropriate installed server is selected from the file extension (gopls, rust-analyzer, typescript-language-server, pyright-langserver, or clangd).
