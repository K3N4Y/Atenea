Delegate a well-scoped task to a fresh subagent without giving it the parent conversation. Ordinary task delegation is one level deep. When the user explicitly activates Recursive Agent Harness mode, capable children may delegate recursively and bash receives the separate batch-spawning capability. Work inline when delegation would merely add handoff latency.

## Input grammar
- `subagent_type` and a self-contained `prompt` are required. The type must be from the live catalog below.
- `output_schema` optionally validates the child result as JSON; with `worktree=true`, the tool returns it inside a `{"result":...,"worktree":"..."}` envelope.
- `timeout_ms` is an optional positive execution deadline.
- `detached=true` starts background work and returns a job ID for `task_status`, `task_wait`, or `task_cancel`.
- `worktree=true` requests an isolated workspace when the selected runtime supports it.

## Examples
- `{"subagent_type":"explorer","prompt":"Find every caller of Foo and report path:line evidence."}` delegates read-only investigation.
- `{"subagent_type":"tester","prompt":"Run the focused behavior checks and report exact commands and failures.","timeout_ms":120000}` delegates verification with a deadline.
- Start independent investigations as parallel task calls in one turn, not one agent after another.

## Recoverable failures
- Unknown `subagent_type`: choose one from the catalog below and retry with the same complete prompt.
- Timeout or exhausted budget: narrow the assignment before retrying; do not blindly raise limits.
- Invalid structured report: clarify the prompt or `output_schema` and retry only the failed slice.
- Worktree unavailable: run without isolation only when shared-workspace execution is safe; otherwise report the prerequisite.
- Recursive or script batching unavailable: continue with ordinary direct task calls; RAH must be activated explicitly by the user.

## Anti-patterns
- WRONG: ask a subagent to interpret the user's entire request or create the top-level plan. RIGHT: pass one scoped slice with all requirements and expected evidence.
- WRONG: delegate one task and wait while doing nothing. RIGHT: work inline or continue an independent slice yourself.
- WRONG: serialize independent tasks. RIGHT: dispatch them together.

<critical>
- Delegate scoped, independent work; retain ownership of intent, decomposition, and integration.
- Prompts must be self-contained because children do not see the parent conversation.
- Ordinary task delegation remains one level deep. Recursive and script spawning are available only in explicitly activated RAH mode and stop at the configured depth.
- Parallelize only real independence, and verify subagent claims before integration.
</critical>
